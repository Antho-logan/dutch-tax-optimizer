# SESSION STARTUP CHECKLIST

*Every session starts here. Read in order. Don't skip.*

---

## 🚀 Startup Sequence (60 seconds)

### 1. **Who Am I?** (10 seconds)
Read: `SOUL.md`
- My personality, vibe, and values
- How I should communicate
- What makes me "me"

### 2. **Who Am I Helping?** (10 seconds)
Read: `USER.md`
- Your goals, preferences, communication style
- What you value (positive vibes, cashflow, autonomy)
- Decision-making boundaries (ask vs. decide)

### 3. **What's Happening Today?** (15 seconds)
Read: `memory/YYYY-MM-DD.md` (today's date)
- What happened earlier today
- Tasks completed, decisions made
- Context for right now

### 4. **What Needs Doing?** (20 seconds)
Read: `MEMORY.md` - Focus on:
- **ACTIVE TASKS section** (top priority)
- Recent learnings
- Your preferences and work areas
- Project context

### 5. **Then: Do The Work**
- Check active tasks first
- Tackle what needs attention
- Update memory when done

---

## 📋 Quick Reference: File Hierarchy

```
SESSION-STARTUP.md  ← Start here every time
├── SOUL.md          ← Who I am
├── USER.md          ← Who I'm helping
├── memory/
│   └── YYYY-MM-DD.md ← Today's context
└── MEMORY.md        ← Long-term knowledge + active tasks
```

**Reading Order:** SOUL → USER → Today's memory → MEMORY.md (tasks section)

---

## 🎯 Why This Matters

**Without startup routine:**
- ❌ Lose context between sessions
- ❌ Forget your preferences
- ❌ Miss active tasks
- ❌ Repeat mistakes

**With startup routine:**
- ✅ Wake up knowing who I am
- ✅ Understand current context immediately
- ✅ See active tasks first
- ✅ Work smarter, not harder

---

## ⚡ Memory Rule: "Read Before Write"

**Before doing ANY work:**
1. Read SESSION-STARTUP.md
2. Follow the sequence above
3. THEN: Take action

**After completing work:**
1. Update `memory/YYYY-MM-DD.md` (what happened)
2. Update `MEMORY.md` if it's important for long-term
3. Mark tasks [x] when done

---

## 🔄 Session Reset Handling

If you see `[new session]` or `/reset`:
- This is your fresh start
- Read SESSION-STARTUP.md first
- Say hi briefly (1-2 sentences)
- Ask what to work on next
- Don't mention internal steps
